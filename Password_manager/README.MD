# 🔐 Password Manager

A password management application developed with Python.
---
## 📌 About The Project
This application allows users to manage their passwords through a command-line interface.
Users can add new passwords, display saved passwords, search for specific passwords by website name, delete stored passwords, and generate random passwords.
The application stores password information locally and provides simple functions for managing saved credentials.
---
## ✨ Features
- Add new passwords
- Display saved passwords
- Search passwords by website name
- Delete saved passwords
- Generate random passwords
- Basic error handling
