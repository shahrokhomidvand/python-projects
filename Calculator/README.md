Python Calculator

A simple calculator application developed with Python.
This project was created to practice fundamental Python programming concepts and build a small functional application.

## 📌 About The Project
This command-line calculator allows users to perform basic mathematical operations.
The project focuses on practicing Python basics such as functions, user input, and conditional statements.
---
## ✨ Features
- Addition
- Subtraction
- Multiplication
- Division
- User input handling
- Basic error handling

 Python
